# Triage Labels

工程技能使用五个规范 triage 状态。下表将其映射到本仓库 GitHub Issue 的默认标签字符串。

| 技能中的状态 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该议题 |
| `needs-info` | `needs-info` | 等待报告人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由代理实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或验收 |
| `wontfix` | `wontfix` | 不会处理 |

每个议题还必须有且仅有一个类别标签：`bug` 或 `enhancement`。若状态标签冲突，先停止实施并修正标签。
