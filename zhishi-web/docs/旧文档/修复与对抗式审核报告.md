### P0 安全与构建加固

| 问题 | 修复 | 文件 |

| 鉴权旁路可能进生产 | `devAuth.ts` 加 `import.meta.env.DEV` 编译期兜底；`vite.config.ts` 用 `loadEnv` 生产构建硬拦截；`.env.development.local` 隔离 dev 旁路 | devAuth.ts, vite.config.ts, .env.* |

## 二、对抗式审核结论

子代理从 6 维度证伪每项修复，发现 **3 个 P1 blocker + 7 个 P2**，误报已剔除。所有 P1 已当场修复。

### 已修复的 P1 blocker

1. **apiStream 缺超时/取消**（client.ts）→ 补首字节超时、外部 signal、SSE `JSON.parse` try/catch 防御、`reader.cancel()` 释放流
2. **useConfirm 卸载/并发 Promise 永久 pending**（useConfirm.tsx）→ ref 持有 resolve，卸载时 `resolve(false)` 兜底；并发覆盖时先解决旧 Promise
3. **Notice 全 tone 用 role="alert"**（Notice.tsx，a11y）→ error 用 `role="alert"`，success/info 用 `role="status"`

### 已修复的 P2

- vite.config `process.env` 读不到 .env → 改用 `loadEnv`
- ChatPage `token` 残留守卫 → 改用 `status !== "authenticated"`
- 404 页 `<a href>` 整页刷新 → 改 `<Link to>`
- useHealth 双层 catch 死分支 → 简化为单层

### 误报确认（无需修）

- Suspense 在 Protected 内会闪烁 → 不会，鉴权同步判定后才渲染 Suspense
- lazy `.then(m => ({default}))` 写法 → 标准
- StatCard/empty.tsx 迁移遗漏 → 全部更新，无残留
- KnowledgeBasePage Dialog 布局重叠 → `pr-12` 让位，不重叠
- refreshOnce 死锁/无限等待 → `.finally` 清空，无死锁
- apiStream 连续 401 无限重试 → 只检查一次 401，无循环
