## 一、知序是什么

| 层级 | 内容 |
|---|---|
| **公司级战略定位** | 自主学习者的 **AI 学习操作系统** |
| **用户级产品表达** | 一个会越来越懂你的 **AI 私人学习私教** |
| **当前商业切入口** | **考研**，优先 408 / 数学一等高结构、高压力学习场景 |
| **长期核心资产** | **长期个人认知状态 + 学习行动系统** |

产品边界：所有具有"目标—知识结构—学习证据—反馈—时间约束"的自主学习任务。

## 二、产品设计（五个模块）

| 模块                           | 一句话                                                 |
| ---------------------------- | --------------------------------------------------- |
| **A  主 AI / General Tutor**  | 用户和"知序这个人"长期沟通的地方——聊目标、调计划、说"你判断得不对"                |
| **B  Learning Workspace AI** | 与当前资料强绑定的 AI——对着 PDF 里某一句话直接发问                      |
| **C  用户初次实验**                | 上传真实资料 → 解析＋OCR＋向量化 → 3~5 轮对话校准 → 第一版 Learner State |
| **D  学习路径设计**                | 不强迫先填目标；用户真提出需求才出方案，始终保留"用户可以改变方案"                  |
| **E  资料上传核心**                | 教材＝在学什么、错题＝哪里可能出问题、笔记＝怎么理解的、计划＝准备怎么学                |

> [!tip] 核心判断（壁垒）
> ==功能不是壁垒；让所有功能围绕同一个人状态运转，才是壁垒。==
> 闪卡只是闪卡——但知序的闪卡、测试、日历，都知道这个人现在需要什么。

## 四、股权架构（双公司）

```
            刘祥（创始人/实际控制人）
            ┌─────────┴─────────┐
    知序主公司              管理服务有限公司
  （资产与业务公司）            （人的公司）
  刘祥 90%＋管理公司10%   刘祥64%＋其他20%＋激励池16%
```

| 主公司权益 | 最终享有人 | 比例 |
|---|---|---:|
| 刘祥直接持有 | 刘祥 | 90% |
| 管理公司10% → 刘祥64% | 刘祥（间接） | 6.4% |
| 管理公司10% → 其他股东20% | 其他股东＝法代本人 | 2% |
| 管理公司10% → 激励池16% | 激励池 | 1.6% |
| **刘祥合计** | | **96.4%** |

> [!warning] 五条核心规则
> 1. 激励只发生在管理公司层，不直接稀释主公司股权
> 2. 16%激励池＝预留额度，具体工具（期权/限制性股权/虚拟权益/代持）由律师设计
> 3. 管理公司法代＝核心管理人员（其他20%股东），非刘祥、非挂名
> 4. 服务费按独立交易原则定价并留档


注册顺序：先管理公司（核名通过）→ 再主公司（直接登记"刘祥90%＋管理服务公司10%"）。认缴期限按新《公司法》由律师/代办确认。

## 五、市场推广（四条线）

| 线           | 定位            | 干什么                                                |
| ----------- | ------------- | -------------------------------------------------- |
| **官方 IP 线** | 内容本身就是产品 Demo | 官方号＋创始人IP＋产品号，持续讲"为什么你刷题还是不会"                      |
| **小红书达人线**  | 精准种草＋搜索承接     | 考研/408/数学一垂类中小博主 × 真实任务式 brief（A–E 五个方向）           |
| **抖音线**     | 制造认知＋快速曝光     | 30~60秒 Demo 视频：错题→分析→断点→修复→**状态更新→计划改变**（最后两步是记忆点） |
| **招募线**     | 验证价值＋形成口碑     | 「知序学习者招募计划」分级报名（最低10道错题照片），校园私域优先                  |

转化链路：**免费初诊 → 深度体验 → 持续订阅**
预算纪律：总池 **5万**、首轮 **5000**，跑出合格内容才集中加码。
