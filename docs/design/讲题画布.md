# 讲题画布：存储与隔离

> 日期：2026-09-12  
> 对照：知拾 `ChatCanvasSidebar` / `show_plot` / `show_canvas`；设计稿公告板「Tina 讲题画布」

---

## 1. 产品边界

- **做**：Tina / 辅导讲题时，对话旁副屏显示函数图或自包含 HTML 示意；气泡里有入口卡片，一点就打开；可拖宽、可收起。
- **不做**：自由白板、跨用户共享板、插件市场式画布。

---

## 2. 数据放哪（隔离）

画布**不是**独立资源表。内容挂在**当前用户的聊天消息 `payload`** 上：

| 字段 | 含义 |
| --- | --- |
| `payload.plots[]` | 函数图（expressions + x 范围）；副屏/索引用 |
| `payload.canvases[]` | HTML/SVG 片段（已服务端清洗）；副屏/索引用 |
| `payload.blocks[]` | **气泡渲染主序**：正文与 tip / plot / canvas / question / onboarding 按 SSE 出现时间交错 |

持久化沿用现有路径：

- `storage_service.save_chat_history(user_id, session_id, …)`
- 缓存键带 `user_id` + `session_id`

因此隔离规则与聊天一致：只认登录态 `user_id`；读/写/删会话前校验归属；注销/删会话一并清掉。

副屏「打开哪块、多宽」：浏览器 `localStorage`（按本机）；不写进公共存储。

---

## 3. 协议

SSE（公开白名单）：

- `type: show_plot` + `plot: { id, title?, expressions, x_min, x_max }`
- `type: show_canvas` + `canvas: { id, title?, html }`

工具（Agent）：

- `show_plot(expression, title?, x_min?, x_max?)` — 普通 y=f(x)
- `show_canvas(html, title?)` — 圆、参数方程等；禁止外链脚本 / iframe（`sanitize_canvas_html`）

---

## 4. 安全

- HTML 仅服务端清洗后入库与下发；iframe `sandbox="allow-scripts"` + CSP。
- 前端不接受「任意 URL 画布」；不把未清洗 HTML 当可信。
