主页 · 今日任务

每天少量可跳转的事：上传、出题、刷题。做完由程序判定，不用自己勾选。点任务后面的按钮，直接进对的页面——这是最容易上瘾的一层。

Tina 对话

流式聊天，能检索自己的书与页码；结合目标和今日安排说话。新手可用对话走完引导，确认称呼、目标与第一份资料。

资料 · 按页出题

上传教材进学习区，解析成分页与章节目录。按章勾页批量出题，可排队；扫描件尽量保留配图。题入库带页码与知识点。

刷题 · 辅导

对 / 错 / 不会。不会可看解析与原文回溯，可进入苏格拉底式辅导。薄弱点可再练一组，和进度页能对上。

目标

一人强调一条进行中的长期目标。任务围着它派；详情里能看到相关材料与推进。改目标可以找 Tina。

学科掌握主线

书可标封闭学科；出题受词表约束；作答可回写掌握。主线已差不多接通，驾驶室要好看懂，还差建档等体验收口。

排期 讲题

任务把人带进辅导 / Tina；画布让高数「讲得见」。对话旁出现函数图像或小演示，气泡里有入口卡片，一点就在副屏打开，可拖宽、可收起。

后端插件扩展

排期 骨架

系统要能往外挂能力，不必每次硬改主仓。先做官方模块扩展点：注册、启停、权限边界清楚；部署侧用环境开关统一打开。

现阶段不做每用户安装，更不做插件市场。画布、学科工具等可以先以内置官方模块的形式挂上扩展点；市场是更远期的事。

收口与上线

收口 其后 · 并行

TCN 体验：补建档、Key、失败不挡学习，让驾驶室里的掌握度敢看。通知 · 提醒 · 画像：到点能喊、顶栏有信、画像能生成；契约对齐后再合，不抢驾驶室与画布。

真人验收：注册登录稳、核心链路无阻断。一个外人独立走完「看任务 → 点进去 → 做完」。用量继续记账；强制限额与插件市场不进本季上线故事。
