## 2. 今日任务 + 检查器（第二期）

Blocked by：#15、#16、#17

- 检查器挂在上传成功 / 出题页上已有题 / 交卷后面，响应带 `completed_tasks`

- 删号级联：表结构找罗洁一起看

不要用 `dashboard/suggestions` 或 `training_plans` 冒充今日任务。
