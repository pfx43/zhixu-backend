# 驾驶室实现边界

> 对照设计稿 `docs/dashboard_v3.html`  
> 日期：2026-09-12  
> 原则：**有真数据就接；没有就不编。假周环比、假人格、假 Learning OS 行动一律不做。**

---

## 1. 已经能做（前端已接或可接）

| 设计块 | 数据来源 | 说明 |
| --- | --- | --- |
| 掌握标尺 / overall % | TCN `summary.overall_mastery` | 无数据时降级文案，不显示假百分比 |
| 目标行 · 标题 / 剩余天数 | 知序当前目标 | 「进度需加速」仅按掌握度粗判，非考试倒计时算法 |
| 三行薄弱 / 形成 / 稳定 | `gaps`；无 gaps 时用刷题 tag 正确率 | 贴近 v3 的「极限 / 微分 / 积分」叙事；不是学科大类一行 |
| Tina 判断（lead / 证据 / 结论） | gaps、vulnerabilities、lvr_alert + 本地 tag 统计 | 模板句，非大模型长文；证据条来自近期知识点正确率 |
| 主 CTA「开始修复 ···」 | 最弱 gap → `/practice` | 暂不能按节点精确出题，先跳刷题 |
| 建议行动：修复 / 验证 / 巩固 | gaps → vulnerabilities → 今日待办任务填满 | **不**调用 TCN Learning OS（`/v1/user/learning/*`） |
| 连击 · 本周点阵 · 今日题数/正确率 | heatmap + analytics | 真连击；设计稿里的「周叙事升幅」不做 |
| 已激活知识域 | 学习路径 / 资料 domain | 跳转 `/path` |
| Tina 说（侧栏一句） | 已有 suggestions | 有则显示 |
| 认知画像（轻量） | 昵称、答题次数、LVR 等级、薄弱行 | 只展示结构信号 |

部署注意：需配置 `TCN_API_KEY`，注册/登录建档成功后掌握度才会持续更新。缺 Key 时注册不挡，但驾驶室可能长期无节点掌握度。

## 2. 设计稿有、当前不能当真（隐藏或诚实降级）

| 设计稿文案 / 块 | 为何不能做 | 当前处理 |
| --- | --- | --- |
| 「较上周 +6%」 | 无周快照对比接口；本地也未存周掌握度 | **不展示**，避免假增长 |
| 「战略型学习者 / 高效时段 / 焦虑」等人格 | TCN profile 未产品化接入；知序侧无稳定人格模型 | **不展示假人格**；文案说明深度画像未接入 |
| 「查看完整认知画像 →」 | 无独立画像页 | **不放入口** |
| 「8/24 → 8/31，62%→68%」周叙事 | 同上，无历史掌握度时间线 | **不展示**；连击区只写连击与今日作答 |
| Learning OS：goals / today / evidence 驱动的修复链 | 产品口径明确：任务源是知序日任务，不是 TCN Learning OS | **不接**；行动条用 gaps + 日任务 |
| 行动卡「25 分钟 / 改善 7 个后续节点」精确耗时与收益 | 无估时模型；`children_count` 只是图谱邻居规模 | 可写「影响后续约 N 个节点」；**不写分钟数与「+x%」** |
| Tina 长文「概念边界还没建立」级诊断 | 需讲题画布 + 更强诊断管线 | 用规则模板；画布另排期 |
| 按节点精确「开始修复」出一组针对性题 | 刷题池尚未按 `node_id` 过滤到产品级 | CTA 先到 `/practice` |

## 3. 和主页的分工（不变）

- **主页**：问候、目标摘要、今日任务（点一下去做）。  
- **驾驶室**：标尺、掌握、为什么这样排、建议行动入口；不重复做完整任务板。

---

## 4. 后续若要补齐「不能做」项，需要什么

1. **周环比 / 周叙事**：定期落库 overall（或按日）快照，或 TCN 提供历史 summary。  
2. **深度画像**：明确用 TCN `profile` 还是自研；字段稳定后再开「完整画像」页。  
3. **按节点修复**：刷题/出题支持按 gap `node_id`（或 tag）过滤。  
4. **估时与收益**：单独产品规则，不要直接抄 Learning OS。
